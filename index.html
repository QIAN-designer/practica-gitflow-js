Documentació: Metodologia Git Flow

1. Introducció Teòrica

Git: És un sistema de control de versions distribuït que permet registrar els canvis realitzats sobre arxius de codi font al llarg del temps, facilitant el treball en equip i la traçabilitat.

Metodologia Git Flow: És un model d'organització de branques proposat per Vincent Driessen que assigna rols específics a diferents tipus de branques:

  • main / master: Conté exclusivament el codi en producció, estable i etiquetat amb versions (tags).
  • develop: Branca de desenvolupament principal on s'integren les noves funcionalitats preparades.
  • feature/*: Branques auxiliars temporals per desenvolupar característiques concretes. Neixen de develop i es fusionen de nou a develop.
  • release/*: Branques per preparar el llançament d'una versió, ajustar detalls menors i etiquetar. Es fusionen tant a main com a develop.
  • hotfix/*: Branques d'emergència creades a partir de main per solucionar problemes detectats a producció sense haver d'esperar al cicle de desenvolupament ordinari.

Per què l'utilitzem? Permet a múltiples desenvolupadors col·laborar en paral·lel sense interferir entre ells ni comprometre l'estabilitat del codi principal en producció.
