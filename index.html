Curs de JavaScript: Interaccions amb el DOM

Benvinguts al Curs

Aquest curs està dissenyat per aprendre a interactuar de manera dinàmica amb els elements del DOM mitjançant JavaScript pur.

Modificació d'Atributs HTML

Podem utilitzar mètodes com setAttribute() o l'accés directe a propietats de l'element per variar atributs com src, href o alt.

Modificació d'Estils CSS

A través de la propietat element.style podem aplicar canvis visuals directes sobre les regles CSS d'un element HTML.
